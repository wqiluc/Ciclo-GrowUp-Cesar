QUIZ - AGENTES DE IA (CICLO GROWUP CESAR)

Questão 1:
Pergunta: O que é um Agente de IA?
Resposta Correta: É quando fornecemos a capacidade para que o modelo de LLM consiga interagir consigo mesmo para criar uma resposta melhor.

Questão 2:
Pergunta: Quais das opções abaixo são componentes de Agente de IA. 1. Memória; 2. Histórico de Tarefas (Tarefas); 3. Ferramentas auxiliares; 4. Modelo de LLM.
Resposta Correta: 1, 2, 3 e 4

Questão 3:
Pergunta: Qual das afirmações abaixo não é um benefício de utilizar múltiplos agentes de IA?
Resposta Correta: Apenas modelo do Chat GPT possui suporte a múltiplos agentes de IA

Questão 4:
Pergunta: O que é o Crew AI?
Resposta Correta: Sistema que coordena múltiplos agentes de IA para trabalharem juntos e realizarem tarefas complexas de forma colaborativa.

Questão 5:
Pergunta: Considerando apresentação das ferramentas de Crew AI e AutoGen Studio, quais das afirmações estão corretas. 1. No Crew AI, um Agent é uma entidade autônoma que pode executar tarefas específicas dentro de um fluxo de trabalho; 2. No Crew AI, uma Task representa um conjunto de regras que define como os agentes se comunicam entre si; 3. O AutoGen Studio é uma plataforma que facilita a criação e o gerenciamento de agentes de IA autônomos; 4. O AutoGen Studio possui ferramentas de low-code para facilitar a configuração e uso de agentes de IA.
Resposta Correta: Apenas as afirmações 1, 3 e 4 estão corretas

Questão 6:
Pergunta: Para que servem as tools no Crew AI?
Resposta Correta: As tools permitem que os agentes executem ações externas, como buscar informações ou interagir com APIs.
