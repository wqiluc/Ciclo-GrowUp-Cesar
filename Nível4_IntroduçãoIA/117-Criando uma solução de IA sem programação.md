<h2 align="left">🧩 A ideia do No-Code AI</h2>

Não é preciso saber programar para colocar uma solução de IA no ar: plataformas **no-code** conectam um modelo genérico (visto na aula de AI Applying) a uma interface visual de configuração — o usuário monta fluxos, regras e integrações arrastando blocos, sem escrever código.

---

## 🧰 Ferramentas comuns

| Ferramenta | Uso típico |
| :--- | :--- |
| **Custom GPTs (OpenAI)** | Assistente especializado configurado via GPT Builder |
| **Voiceflow** | Chatbots e assistentes de voz com fluxo visual |
| **Zapier AI / Make.com** | Automações que chamam um modelo de IA como um passo do fluxo |
| **Chatbase / Poe** | Chatbots treinados sobre uma base de conhecimento própria |
| **Google AI Studio** | Ajuste e teste de prompts sobre modelos Gemini via interface |

---

## ⚖️ No-code x programação

| | No-Code | Programação |
| :--- | :--- | :--- |
| Barreira de entrada | Baixa — interface visual | Exige conhecimento de código |
| Flexibilidade | Limitada ao que a plataforma oferece | Total — qualquer integração é possível |
| Velocidade para protótipo | Alta | Menor |
| Controle sobre custo/escala | Depende do plano da plataforma | Total, via infraestrutura própria |

---

## ✅ Resumo

- Soluções de IA **no-code** conectam modelos genéricos a interfaces visuais, permitindo criar assistentes e automações sem escrever código.
- Ferramentas como Custom GPTs, Voiceflow, Zapier/Make e Chatbase cobrem a maioria dos casos de uso simples.
- A troca é **flexibilidade por velocidade**: no-code entrega protótipos rápidos, mas com menos controle do que uma solução programada.
