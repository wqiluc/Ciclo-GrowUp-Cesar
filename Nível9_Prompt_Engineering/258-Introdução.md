<h2 align="left">🎯 Objetivo</h2>

Entender o que é **Prompt Engineering** e por que a forma de perguntar muda a qualidade da resposta.

---

## 🔍 A analogia da busca no Google

No vídeo, duas buscas sobre o mesmo assunto:

| Busca "conversa" | Busca "otimizada" |
| :--- | :--- |
| *qual o melhor tipo de saque no tênis pinpoint ou plataforma?* | *Tênis Saque pinpoint x saque plataforma* |

Com o tempo aprendemos a "falar a língua" do buscador: palavras-chave, comparação direta, sem ruído.
Com LLMs é a mesma ideia, só que ao contrário: o modelo entende linguagem natural, então ganhamos mais com **contexto e clareza** do que com palavras soltas.

---

## 🧠 O que é Prompt Engineering

> A prática de **escrever e iterar instruções** para que um LLM gere a saída que você realmente quer.

| Prompt fraco | Prompt bom |
| :--- | :--- |
| Vago ("me fala sobre saque") | Específico (objetivo, público, formato) |
| Sem contexto | Com contexto (quem sou, para que serve) |
| Sem formato de saída | Formato definido (tabela, lista, JSON) |
| Uma tentativa só | Iterado até ficar bom |

## ✅ Resumo

- O jeito de perguntar define a qualidade da resposta, no Google e nos LLMs.
- Prompt Engineering = instruções claras + contexto + formato + iteração.
- Não é "truque": é comunicar bem o que se quer.
