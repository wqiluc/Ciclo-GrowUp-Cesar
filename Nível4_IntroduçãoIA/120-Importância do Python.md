<h2 align="left">🐍 Por que Python domina IA</h2>

Python virou a linguagem padrão de IA por três motivos: **sintaxe simples** (foco no problema, não na linguagem), **comunidade enorme** (documentação, tutoriais, respostas prontas) e, principalmente, um **ecossistema de bibliotecas** que cobre tanto AI Applying quanto AI Creating:

| Biblioteca | Usada para |
| :--- | :--- |
| **NumPy / pandas** | Manipulação numérica e de dados tabulares |
| **scikit-learn** | Classical ML (Regressão, Decision Tree, Random Forest, etc.) |
| **TensorFlow / PyTorch** | Deep Learning — treino de redes neurais |
| **Hugging Face Transformers** | Uso e ajuste de modelos de linguagem pré-treinados |
| **OpenAI SDK** | Consumo de modelos via API (AI Applying) |

---

## ✅ Resumo

- Python é dominante em IA pela combinação de **sintaxe simples + comunidade + bibliotecas prontas**.
- O mesmo ecossistema cobre tanto **consumir IA pronta** (OpenAI SDK, Hugging Face) quanto **treinar modelos do zero** (scikit-learn, TensorFlow, PyTorch).
- É a ponte prática entre a teoria vista até aqui e o código das próximas aulas (AI Applying com Python, AI Creating com Python).
